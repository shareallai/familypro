如果你看到的还是 X Premium、SuperGrok Lite、SuperGrok 和 Heavy 的对比，先别按旧表下单。xAI 在 **2026 年 10 月 12 日**[发布 The X Subscription](https://x.ai/news/x-subscription)，把 Grok、Grok Bot、Cursor 和 X 权益放进统一订阅，新用户的选择已经变了。

**数据核对日期：2026-10-15。本文美元价格为官方标价，仅供参考，未含适用税费；地区价格、优惠及购买资格以账户结账页为准。** 本文保留旧套餐名称的解释，帮助已有订阅的读者判断变化。完整的新套餐价格表与迁移流程，见[Grok 新套餐价格与迁移指南](../xai-grok-x-subscription-plan-guide/)。

## 1. 新用户现在应该看什么套餐

按[官方价格文档](https://docs.x.ai/x-subscription/pricing)，新的自助订阅分为 Free、Plus、Premium、Super 和 Ultra。Plus 为 $8/月，Premium 为 $30/月，Super 为 $100/月，Ultra 为 $200/月。

这套体系将符合规则的 Grok 与 Cursor 用量放在同一周额度里。连接个人 X 账号后，Plus 提供蓝标、创作者工具和较少广告；Premium 及以上提供完整 X Premium+ 权益，详见 [X 官方统一订阅说明](https://help.x.com/en/using-x/x-subscription)。

因此，旧文中“先决定买 X 还是买 Grok”的建议不再适合作为新用户的主要选购路径。现在更需要判断的是：需要哪些功能、每周用量有多大，以及是否会另用第三方模型。

## 2. 旧套餐名称应该怎么理解

下面用于辨认原账单和旧教程中的名称，不是当前新用户的购买清单。

| 你见到的名字 | 所属体系 | 现在应注意什么 |
| --- | --- | --- |
| X Basic、Premium、Premium+ | 原 X 平台订阅 | 原 X Premium 与统一订阅 Premium 是不同套餐，不能只看名字 |
| SuperGrok Lite、SuperGrok | 原 Grok 独立订阅 | 已有订阅先看原续费价格和权益；新用户看统一订阅 |
| SuperGrok Plus | 原 Grok 订阅中的另一档名称 | 不等于统一订阅中的 Plus |
| SuperGrok Heavy | 原 Grok 高档订阅 | 不能仅凭价格或档位认定等同于 Ultra |
| Free、Plus、Premium、Super、Ultra | The X Subscription | 属于新的统一订阅体系 |

[发布公告](https://x.ai/news/x-subscription)将新 Premium 概括为包含 SuperGrok、Cursor Pro 和 X Premium+ 的权益。但这不代表三个旧套餐的每一项额度都直接叠加：尤其是 Cursor 第三方模型的计费，需要单独核对。

## 3. SuperGrok 和 Heavy 老用户要马上换吗

**目前不用。** [官方保留规则](https://docs.x.ai/x-subscription/do-i-have-to-switch)明确说明，切换是可选的；不更改或取消，当前套餐继续。官方公告同时说明，原有价格和功能可继续保留。

如果你只用 Grok、原额度够用，也不需要 Cursor 或 X 权益，可以先保留原订阅。若同时为多个产品付费，则值得把新套餐报价与实际账单总额放在一起比较。

Heavy 用户尤其应核对自己依赖的模型、功能和优惠。当前公开的新套餐表没有提供足以证明 Heavy 与 Ultra 完全等同的逐项对照，不能把“Ultra 更便宜”直接理解为“原权益全部保留且价格下降”。

保留原套餐是当前规则，不应被写成永久价格保证；后续变化仍需以官方通知和续费条款为准。

## 4. 共享周额度，不能按聊天次数理解

[官方用量说明](https://docs.x.ai/x-subscription/usage-limits)将额度定义为同一付费席位跨 Grok 与 Cursor 的合资格第一方用量。不同任务消耗不同，不能把 Premium 的 4 倍、Super 的 15 倍、Ultra 的 50 倍 Plus 用量换算成固定的每日提问或视频次数。

例如，白天在 Cursor 中用 Grok 模型做大型代码任务，会减少同周可用于 Grok 其他功能的额度。Grok Bot 从 Premium 起包含，也使用同一周额度。

此外，[官网计费说明](https://x.ai/pricing)明确区分了两项额外费用：Cursor 中的第三方模型不包含在订阅用量内；Grok API 虽提供访问资格，但调用按模型标准价格单独计费，不消耗套餐周额度。订阅费不代表这些调用已经付过钱。

## 5. 迁移前先确认，再合并账号

如果新套餐确实更适合你，先记录原订阅的购买渠道、续费价格和到期日，再进入[官方账户合并流程](https://docs.x.ai/x-subscription/unify-accounts)。选中正确的 Grok、Cursor 和个人 X 账号后再确认，特别留意工作账号与私人账号。

**合并完成后无法撤回，官方支持也不能恢复。** 符合条件的旧订阅会按剩余时间退款，但 Apple 购买的 Cursor 需要自行取消并向 Apple 申请退款；Google Play 购买的订阅也需要检查是否仍会续费。

新用户可直接阅读[Grok 新套餐价格、功能与选择建议](../xai-grok-x-subscription-plan-guide/)。老用户则先用自己的账单和真实任务来比较，再决定是否换到共享周额度的体系。
