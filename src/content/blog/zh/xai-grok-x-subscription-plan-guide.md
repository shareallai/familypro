如果你刚打开 xAI 定价页，发现 SuperGrok 和 Heavy 不再是新套餐表里的主角，先别急着取消原订阅。**新用户已经转向统一套餐，老用户目前仍可保留原套餐；主动迁移后，才按新规则使用和计费。**

官方在 **2026 年 10 月 12 日**发布 [The X Subscription 公告](https://x.ai/news/x-subscription)，把 Grok、Grok Bot、Cursor 和 X 权益放到同一订阅体系中。这篇文章重点回答两个问题：新用户买哪一档更合适，以及原来的 SuperGrok、SuperGrok Heavy 用户是否该切换。

**数据核对日期：2026-10-13。下文美元价格为官方标价，仅供参考，未含适用税费；实际支付金额、促销和可用入口以账户结账页为准。** 迁移入口仍在逐步开放，账户暂时没有入口，不代表旧订阅已失效。

## 1. 新套餐变了什么：从分别订阅到共用一套额度

按 [官方订阅总览](https://docs.x.ai/x-subscription/overview)，The X Subscription 把 Grok 与 Cursor 纳入一个工作区和账单，二者共享每周包含的第一方 AI 用量。X 权益则需要连接个人 X 账号，按所选档位生效。

这对同时使用 Grok 和 Cursor 的人更有吸引力：不用单独为两个产品分配预算，不用完的额度可以留给另一个产品。但“统一订阅”不等于所有模型、所有任务都无限量使用，尤其不能理解成买了 Grok 套餐，就免费获得 Cursor 中的 Claude 或 GPT 使用额度。

名称也需要重新辨认：**新 Premium 是统一订阅中的一档，新 Super 也不能仅凭名称认定为旧 SuperGrok 的更名版。** 比较时应核对价格、周额度和具体功能，而不是把新旧名称直接对号入座。

## 2. Plus、Premium、Super、Ultra 价格怎么比

下表依据 [官方价格文档](https://docs.x.ai/x-subscription/pricing)。年付折合月费由年价除以 12 计算，便于比较；年付仍是按年付款。

| 套餐 | 月付价格 | 年付价格 | 年付折合月费 | 包含用量，相对 Plus |
| --- | --- | --- | --- | --- |
| Free | $0 | $0 | $0 | 有限访问，不适用倍数比较 |
| Plus | $8/月 | $80/年 | 约 $6.67/月 | 基础档 |
| Premium | $30/月 | $300/年 | $25/月 | 4 倍 |
| Super | $100/月 | $1,000/年 | 约 $83.33/月 | 15 倍 |
| Ultra | $200/月 | $2,000/年 | 约 $166.67/月 | 50 倍 |

Grok Bot 从 Premium 开始包含，Plus 不包含。它消耗同一席位的周额度，并没有另外赠送一份独立用量。

[官网定价页](https://x.ai/pricing)把 Plus 定位为轻量 AI 用户的入口；Premium 增加最新 Grok 模型、更快聊天响应及云端 agent 等能力，Super 进一步提供高峰期模型访问优先权。Ultra 是当前表中用量最大的个人档，但仍有额度边界。

X 部分可以按 [官方 X 权益说明](https://docs.x.ai/x-subscription/x-premium)理解：连接个人账号后，Plus 提供蓝标、创作者工具和较少广告；Premium、Super、Ultra 提供完整 X Premium+ 权益。原本依赖 X Premium+ 功能的人，迁移时至少应比较 Premium，不能因为 Plus 更便宜就默认权益相同。

团队从 $30/席位/月起，可选择 Premium、Super、Ultra，并混合不同档位；需要集中管理和账单时才值得比较 Teams。多人协作时，应按席位计算成本，而不是把个人套餐当成团队共享账号方案。

## 3. 共享周额度怎么用：倍数不是固定提问次数

[用量文档](https://docs.x.ai/x-subscription/usage-limits)明确说明，同一付费席位的合资格第一方 Grok 与 Cursor 使用消耗同一周额度，不同任务的消耗率不同。

因此，Premium 的“4 倍 Plus”不能换算成每天固定多少次聊天、多少张图片或多少条视频。短问答、视频生成和长时间代码任务的消耗不同。例如，你在 Cursor 连续跑了几个大型任务，留给 Grok 的额度就会减少；不使用 Cursor 的一周，则可以把额度集中用于 Grok。后一种灵活性有价值，但并不等于两边各有一份完整限额。

Cursor 中的第三方模型属于额外付费用量，**从第一次使用就单独收费**，不会先抵扣新套餐包含的周额度。超出套餐的第一方用量也属于额外用量，需要充值额度支持。准备切换的人应把“月费”和“额外用量支出”一起算入预算，并检查自动充值和支出上限设置。

团队也有一个容易误解的地方：自助团队计划中，每个付费席位拥有自己的周额度，席位之间不共享；团队共享的是额外用量的预付余额。Enterprise 则按合同处理。

选档前，我建议先观察一个完整周周期的真实消耗，再决定是否长期年付。如果只是偶尔一次任务触顶，可以比较少量充值的成本；如果每周都用到上限，再考虑升级会更有依据。

## 4. 原有 SuperGrok、Heavy 的权益会变吗

### 4.1 不迁移：目前保留原套餐、价格和功能

[官方迁移说明](https://docs.x.ai/x-subscription/do-i-have-to-switch)写明，切换是可选的，当前套餐会继续，除非你更改或取消。[订阅总览](https://docs.x.ai/x-subscription/overview)进一步明确，保留的是原套餐、价格和功能。

对现有 SuperGrok 用户，这意味着无需因为官网换了一张价格表就重新购买。对 SuperGrok Heavy 用户，当前公开说明是面向存量 Grok 订阅的整体保留规则，而不是一张逐项列出 Heavy 权益的专属对照表。**按该规则理解，保留旧 Heavy 订阅并不意味着此次发布就自动失去原权益；但你账户中的特殊折扣、赠送权益和续费安排，仍需逐项核对。**

尤其不要把旧 Heavy 自动当成新 Ultra，也不要把新套餐的 50 倍用量反推成旧 Heavy 的实际限额。公开新套餐表没有完整列出旧 Heavy 专属模型、附加权益与 Ultra 的逐项对应关系；若某一 Heavy 功能是你订阅的主要原因，应先让官方支持确认迁移后的可用性。

### 4.2 以后会不会强制迁移：官方没有承诺永久保留

[发布公告的 FAQ](https://x.ai/news/x-subscription)还说明，未来计划把剩余用户迁移到新套餐，但目前没有时间表，会提前通知。因此，“现在可继续使用旧套餐”不能写成“旧套餐永久不变”。

年付用户也有明确边界：如果不主动升级，已付款的年付期限会继续到期；未来如有变更，将在续费时生效，并提前通知。先查看续费邮件和账单页，比看到新套餐上线就立即取消更稳妥。

### 4.3 主动迁移：改按新档位使用，合并无法撤回

按 [账户合并流程](https://docs.x.ai/x-subscription/unify-accounts)，迁移会把合资格 Grok 与 Cursor 账号统一到一个账户、工作区、套餐和账单。**完成合并后无法撤回，官方支持也不能恢复到合并前的状态。**

这不是先体验几天新套餐、不满意再一键回旧 Heavy 的操作。[取消说明](https://docs.x.ai/x-subscription/cancel)也明确，取消新订阅不会拆开已经合并的账号，也不会恢复原来的 Cursor、SuperGrok 或 X Premium 订阅。

如果你同时订阅旧 Cursor，还要单独核对第三方模型额度。官方公告指出，旧 Cursor 套餐包含的第三方用量会保留到切换前；切换后则适用新订阅的单独计费规则。主要用 Claude 或 GPT 写代码的人，未必会因捆绑了 Grok 而降低总支出。

## 5. 月费和退款怎么衔接，怎样避免重复扣款

[官方账单与退款说明](https://docs.x.ai/x-subscription/invoices-and-refunds)规定，参与迁移的合资格直接计费订阅会被取消，并按原计费周期剩余时间退款；月付和年付都适用。退款退回原支付方式，不会变成新订阅余额。新套餐即时开始并全额收费，退款另行到账，不应把退款金额提前当成结账时的抵扣。

购买渠道会影响处理方式：

- **网页直接付费**：参与迁移的合资格旧订阅自动取消；未纳入迁移的账号订阅不受影响。
- **Apple 购买的 Cursor**：官方不能替你取消或退款，需要在 Apple 订阅设置中处理，否则可能继续扣款。
- **Apple 购买的 Grok、Grok Bot 或 X Premium**：官方取消并向 Apple 请求未使用时间的退款，退款是否批准由 Apple 决定。
- **Google Play 购买的 Grok、Grok Bot 或 X Premium**：迁移后检查 Play 订阅状态，如果仍会自动续费，需要在那里取消。

如果你决定迁移，先记录旧套餐名称、实际续费金额、到期日和当前附加权益，然后从官方入口操作。已有付费 Cursor 的用户，应从 [Cursor 合并入口](https://cursor.com/unify)开始；从 Grok 出发可使用 [xAI 账户合并入口](https://accounts.x.ai/unify)。邮箱不必相同，但必须确认选中了自己真正想合并的账号，尤其不要误把工作账号和私人账号合到一起。

操作完成后，再回到原支付渠道核对续费状态，并查看新工作区用量和账单。不要把“新套餐已经能用”当作“所有旧扣款都已停止”的证据。

## 6. 按你的使用习惯选择，而不是直接买最高档

下面是我的选择建议，不是官方对具体任务次数的保证。

| 你的情况 | 优先考虑 | 决策理由 |
| --- | --- | --- |
| 偶尔问答，还没确定是否长期使用 | Free | 先用实际任务判断是否需要付费 |
| AI 用得少，主要想要 X 蓝标和创作者工具 | Plus | 低预算入口；需要 Grok Bot 时就不适合 |
| 把 Grok 当日常助手，也想尝试代码 agent | Premium | 先从 $30/月观察真实周消耗 |
| 每天跑代码或自动化任务，较低档频繁触顶 | Super | 为稳定的高用量付费，而不是只为套餐名升级 |
| 持续高强度使用，Super 的额度也明显不够 | Ultra | 用量需求已经得到验证后，再承担 $200/月成本 |
| 现有 SuperGrok 使用够用，其他产品用得少 | 先保留旧订阅并比较迁移报价 | 新增捆绑功能未必是你需要的价值 |
| 现有 Heavy，依赖特定模型、折扣或赠送权益 | 核对后再迁移 | 新旧权益尚不能仅凭档位名称判断等价 |
| 主要在 Cursor 使用 Claude 或 GPT | 比较旧套餐与新套餐的总费用 | 新订阅不包含第三方模型用量 |

如果你是新用户，我会建议先月付，跑完一两个正常工作周再决定是否年付。不要为了未来可能用到的任务提前买 Ultra。

如果你是 SuperGrok 或 Heavy 老用户，先打开自己的账单页，比较真实续费价和迁移后的总费用；促销账户尤其不能只按官网标准价判断。只有在所需功能确认保留、共享额度符合使用习惯，并且接受账户合并无法撤回的前提下，迁移才是一个可以落地的选择。
