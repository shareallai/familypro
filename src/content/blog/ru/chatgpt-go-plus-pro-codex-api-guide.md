Выбор ChatGPT Go, Plus или Pro начинается с того, где вы будете работать: обычный Chat, агент для кода и документов или модель в собственном продукте. Доступные модели и способ оплаты зависят от этого выбора.

Тарифы, модели и цены API проверены **2026-10-14**. Суммы в USD указаны **для ориентира**: итоговую цену определяют оформление покупки, местные налоги и счёт. Доступ также зависит от этапа внедрения, клиента и настроек рабочего пространства.

## 1. Go, Plus и Pro: цены и выбор тарифа

[Официальная страница тарифов Work/Codex](https://learn.chatgpt.com/docs/pricing) перечисляет следующие личные планы. Рекомендации не гарантируют фиксированное число задач.

| План | Ориентир цены в месяц, USD | Когда рассматривать |
| --- | --- | --- |
| Free | $0 | Сначала попробовать небольшие задачи |
| Go | $8 | Ограниченный бюджет и лёгкие задачи Codex |
| Plus | $20 | Регулярная работа агента с кодом и документами |
| Pro | $100 / $200 / $500 | Частое достижение лимитов или конкретная потребность в скорости |

У Pro теперь три уровня. Старое описание двух планов с одинаковыми возможностями неполно: доступ к **Ultrafast** указан для Pro $500 и зависит от модели и клиента. Сравнивайте текущие условия покупки и лимиты аккаунта, а не считайте прежние 5x/20x универсальными множителями числа задач.

Для обычных разговоров проверяйте модели и инструменты непосредственно в Chat. Права Work/Codex не описывают выбор моделей в обычном чате.

## 2. Новые модели: GPT-6.1 Sol, GPT-6 Astra и GPT-6 Luna

GPT-5.4 уже не подходит как главный пример новых моделей. [Актуальная документация](https://learn.chatgpt.com/docs/models) разделяет их по задачам:

| Модель | Подходящие задачи | С чего начать |
| --- | --- | --- |
| GPT-6.1 Sol | Многошаговая работа с кодом, приложениями и документами | Сначала попробовать для регулярных сложных задач |
| GPT-6 Astra | Трудные процессы с длительным рассуждением и оценкой решений | Когда сложность оправдывает повышенный расход |
| GPT-6 Luna | Сводки, извлечение, классификация и локальные правки кода | Чёткие повторяющиеся задачи при небольшом бюджете |

В ChatGPT модели **GPT-6.1 Sol, GPT-6 Sol и GPT-6 Luna доступны в Work/Codex, а не в обычном Chat**. Первоначальное внедрение GPT-6.1 Sol включает Plus, Pro, Business, Enterprise и Edu; Free/Go на старте не включены. Для Enterprise/Edu может потребоваться разрешение администратора. Проверяйте доступ в своём аккаунте и клиенте.

OpenAI назначила вывод GPT-5.5 из ChatGPT, Work и Codex на **14 октября 2026 года**. API это изменение не затрагивает. Замените модель в сохранённых настройках, скриптах и запланированных задачах на доступную альтернативу; из этой даты не следует одновременное отключение API.

## 3. Входит ли Codex в подписку и как работают лимиты?

Codex — агент, который понимает, изменяет и выполняет код. В официальных тарифах теперь перечислены Free и Go, без прежнего описания исключительно как временной акции. **Free/Go получают GPT-6 Luna в настольном приложении по мере внедрения**; Plus предлагает больше способов доступа, включая веб, CLI и расширение IDE.

Work и Codex расходуют общий лимит. Модель, контекст, глубина рассуждения и инструменты меняют расход, поэтому одно сообщение не равно фиксированному объёму работы. Старые лимиты сообщений Chat нельзя перевести в число задач Codex, а цены токенов API не позволяют вычислить объём работы в подписке.

Остаток и время сброса смотрите на странице Usage. Plus/Pro могут докупить кредиты ChatGPT после достижения лимитов; это отдельный баланс от API. Попробуйте Luna для узких задач, а Sol или Astra для сложных, прежде чем переходить на более дорогой план.

## 4. Отдельная оплата API и цены новых моделей

Запросы с API key из продукта, скрипта или сервиса оплачиваются через API. Подписка ChatGPT не выдаёт автоматически кредиты API и не компенсирует эти расходы. Codex с входом через ChatGPT использует лимиты подписки; с API key — оплату API.

Ниже — **текстовые тарифы Standard для короткого контекста, проверенные 2026-10-14**. Цены в USD за миллион токенов, только для ориентира.

| ID модели API | Вход | Кэшированный вход | Запись в кэш | Выход |
| --- | --- | --- | --- | --- |
| `gpt-6.1-sol` | $2.00 | $0.10 | $2.50 | $10.00 |
| `gpt-6-astra` | $10.00 | $1.00 | $12.50 | $50.00 |
| `gpt-6-luna` | $0.10 | $0.01 | $0.125 | $0.50 |

Миллион некэшированных входных токенов и 200 000 выходных токенов Sol стоят здесь **$4**, без записи в кэш, инструментов и других сборов. Для длинного контекста действуют другие цены; Batch, Flex, Fast и Ultrafast также могут менять тариф. Рассчитывайте бюджет по [текущим ценам API](https://developers.openai.com/api/docs/pricing), а не только по этой таблице.

## 5. Может ли стороннее приложение использовать лимит Plus/Pro?

Да, если приложение поддерживает эту возможность, а аккаунт соответствует условиям. [Sign in with ChatGPT](https://learn.chatgpt.com/docs/sign-in-with-chatgpt) позволяет разрешить совместимому приложению расходовать существующий лимит Work/Codex. **Вход в аккаунт и разрешение расходовать подписку — разные права**. Кнопка входа через ChatGPT сама по себе не показывает, как оплачиваются запросы.

Это не добавляет новый лимит и не предоставляет универсальный API key. Приложение может взимать собственную плату. Для своей интеграции сначала проверьте поддержку этого способа; обычные запросы с API key по-прежнему оплачиваются отдельно.

## 6. Выбирайте по реальным задачам

Для лёгкой работы начните с Free или Go. Для регулярных сложных задач в Work/Codex проверьте Plus и доступность GPT-6.1 Sol. Сравнивайте три уровня Pro, когда лимиты часто прерывают работу или нужен поддерживаемый режим Ultrafast.

Для собственного продукта отдельно рассчитайте API: испытайте Luna на понятных массовых задачах, Sol — на сложной работе, Astra — там, где это оправдано трудностью. При покупке у посредника уточняйте точный тариф, способ использования аккаунта, права Codex и поддержку. Низкая цена не подтверждает официальные возможности Pro или доступ ко всем моделям.
